<objective>
Stop asking an unprivileged process to do the kernel's act: the run reports honestly that the wake belongs elsewhere, and take-back on exit re-homes accordingly — while a root run keeps today's full behavior.

Purpose: `IOPMSchedulePowerEvent` refused to a user process is not an error to spam about; it is a handoff line. Same for take-back: the run cannot cancel kernel events it could not arm. This plan makes both conditions *designed states*, so Phase 2 can hand the act to the daemon without the run noticing anything but silence.

Output: user-mode runs log one clear handoff line, never a permission failure; root-mode byte-identical behavior.

<objective>
Delete the identity forgery from surfacing: a user-mode run must open the app in its own session directly, with no `launchctl asuser`.

Purpose: `asuser` exists only because a root process must reach *into* someone else's session (Analysis.md's own note: unmeasured, likely not even valid). A process already running as the console user has nothing to forge; the call's removal is the visible sign that the identity-forensics layer is going.

Output: `surface`, as user, is one `open -a`; as root, unchanged. Tests pin both.

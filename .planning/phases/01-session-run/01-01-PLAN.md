<objective>
Move the night run's artifacts and claims onto ground the user owns, so a run without sudo is a complete citizen.

Purpose: today a sudoless run works only as a degraded guest — it logs "cannot write", warns "not locked", and pretends the lock exists. A plain user run must be the *intended* configuration, not the degraded one, before the sudo-once installer can be built on it.

Output: user-mode runs write logs and locks on user-owned ground; root-mode keeps today's paths unchanged; tests protect the split.
